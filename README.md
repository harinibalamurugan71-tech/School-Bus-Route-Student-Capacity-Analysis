# School Bus Route & Student Capacity Analysis

## About the Project

This project is about analyzing school bus data.

It helps to understand:
- How many students travel by bus
- Which route has more students
- How much buses are delayed
- Which trips are overcrowded
- How many students are travelling in each bus

## Tools Used

- Excel
- PostgreSQL
- SQL
- Power BI

## What I Did

1. Cleaned and analyzed the data using Excel.
2. Used PostgreSQL and SQL to analyze the data.
3. Created a dashboard using Power BI.
4. Added charts and filters to make the data easy to understand.

## Dashboard Includes

- Total Trips
- Total Students
- Average Delay
- Students by Route
- Students by Bus
- Crowd Status
- Bus and Route Filters
